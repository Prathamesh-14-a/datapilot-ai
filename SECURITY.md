
# Security Policy

## Supported Versions

Only the latest version of DataPilot AI is actively maintained.

| Version        | Supported |
| -------------- | --------- |
| Latest         | ✅        |
| Older Releases | ❌        |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please do not create a public GitHub issue.

Instead, report it privately.

Email:

**datapilotai.app@gmail.com**

Include:

- Description of the vulnerability
- Steps to reproduce
- Impact
- Possible mitigation (optional)

---

## Response Policy

We aim to:

- Acknowledge reports within **72 hours**
- Investigate all valid reports
- Release fixes as quickly as possible

---

## Scope

Examples include:

- Authentication bypass
- Password reset vulnerabilities
- SQL Injection
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Sensitive data exposure
- API authentication flaws
- Database security issues

---

## Out of Scope

- UI bugs
- Feature requests
- Performance improvements
- General coding questions

---

Thank you for helping keep DataPilot AI secure.
